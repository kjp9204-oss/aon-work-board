# 센터와 AI 협업 업무 인계

- 센터 대시보드는 공지·업무·일정, AI 대시보드는 외부로 공유해도 되는 작업 행동과 인계·검수 결과를 보여줍니다. AI 로그 실데이터와 공지 작성 권한·저장은 화면 검토 뒤 확정합니다.
- Claude와 Codex가 작업을 넘길 때 같은 업무 ID를 사용합니다. 현재 상태와 다음 행동은 AI 대시보드, 승인·결정·검증과 상세 이력은 기존 **김재필 통합 업무보드**에 남깁니다. 이 협업 기록 시트와 이번 앱의 데이터 시트는 별개입니다.
- 블로그 예시 ‘운동은 꼭 30분씩 해야 할까요?’는 실제 게시물이 아닙니다. Claude 글쓰기 기준·근거·사진 요청과 초안 → Codex 이미지·검수와 파일 위치 인계 → Claude 확인·완성 목록 순서입니다. 이미지 또는 빠른 작성에 이전 승인 자료를 사용할 경우 어떤 문서·가이드를 확인했는지 기록합니다.

## 토스 POS 예약 요약

재필님이 요청할 때 **Claude의 Computer Use**로 로그인된 Mac의 토스 POS 예약 화면을 읽기 전용으로 확인합니다. 예약일과 기간, 건수, 시간대별 예약 수 또는 휴무와 확인한 시각만 대시보드에 옮깁니다. 고객 이름·연락처·메모·세션 내역, 직원의 사적 일정, 원본 캡처는 공개 GitHub·협업 대시보드·시트에 넣지 않습니다. 예약·결제 상태와 설정은 바꾸지 않습니다. 로그인이나 앱 접근이 막히면 이전 요약의 확인 시각을 유지하고 갱신 실패를 보고합니다.

## 정기 확인

Claude와 Codex가 대시보드와 업무목록을 정기 확인하는 방향입니다. 실제 두 앱의 예약과 시험 실행이 완료되면 확인 범위와 시간을 기록합니다. 이번 GitHub 이전본은 예약을 실행하지 않습니다.
