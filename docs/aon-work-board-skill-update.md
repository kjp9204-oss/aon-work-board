# aon-work-board 주소·저장 방식 갱신안

실계정과 저장 검증을 통과한 뒤 반영할 문구입니다.

- **업무 화면:** `https://kjp9204-oss.github.io/aon-work-board/`
- **화면 소스:** `https://github.com/kjp9204-oss/aon-work-board`
- **저장:** Google 로그인 후 허용 계정만 Apps Script를 통해 비공개 ‘AON 오늘의 센터 데이터’의 업무와 일정을 읽고 등록·수정합니다.
- **수정 충돌:** 목록을 다시 읽고 최신 revision을 받아 수정합니다. 완료·보류 상태를 사용하며 업무나 일정을 삭제하지 않습니다.
- **인계와 이력:** AI 대시보드에서 인계와 다음 행동을 확인하고, 동일 업무 ID로 ‘김재필 통합 업무보드’에 결정·검증을 남깁니다.
- **예약 요약:** 사용자가 요청한 경우에만 Claude Computer Use로 토스 POS 예약 화면을 읽습니다. 회원 식별 정보나 원본 캡처는 공유 화면에 남기지 않습니다.
