# AON Work Board · 오늘의 센터 이전본

에이온 운동센터의 업무와 센터 일정을 기록하는 보드입니다. 화면과 예시 파일은 GitHub Pages에서 제공하고, 실제 데이터는 재필님 Google Drive의 비공개 **AON 오늘의 센터 데이터** 시트에서 관리합니다.

- 게시 대상: `kjp9204-oss/aon-work-board`
- 검토 승인 후 사용할 주소: `https://kjp9204-oss.github.io/aon-work-board/`
- 화면 원본: `kjp9204-oss/aon-work-dashboard` 커밋 `397ab7dbcfc672753a08af6453e74147bede8ece`의 `server/public`. 새 작업본에서 Google 로그인과 저장 연결, 기존 에이온 로고·아이보리 화면, 센터 운영과 AI 협업 메뉴를 반영했습니다.
- 기존 ChatGPT 사이트와 원본 저장소는 보관합니다.

## 화면과 데이터

| 화면 | 용도 |
| --- | --- |
| 오늘의 센터 · 업무 | 업무 조회·등록·수정, 담당자와 상태 확인 |
| 센터 일정 | 이번 주 일정과 등록된 일정, 일정 등록·수정 |
| AON 블로그 | 기존 ‘한 편의 글이 완성되기까지’ 예시와 원고·이미지·근거·검수·다운로드 |
| AI 대시보드 | Claude → Codex → Claude 블로그 작업 흐름 예시 |
| 공지사항 · 토스 POS 예약 요약 | 권한과 데이터 연결을 검토할 자리 |
| AON 문진표 | 확인된 문진표 Apps Script 주소가 설정되면 바로가기 표시 |

업무·일정 앱은 회원 시스템이 아닙니다. 회원 및 환자 정보, 실제 예약 캡처, 인증 정보, 운영용 시트 ID, 첫 등록 JSON은 이 공개 소스에 넣지 않습니다.

## 로컬 검토

정적 파일을 프로젝트 폴더에서 HTTP 서버로 열어 화면과 메뉴를 확인할 수 있습니다.

```sh
python3 -m http.server 18744 --bind 127.0.0.1
```

[로컬 미리보기](http://127.0.0.1:18744/)는 실사용 계정이나 시트 주소를 설정하기 전에는 읽기 전용 화면입니다. 주소가 준비되면 아래 절차에 따라 연결합니다. 강제 브라우저 새로고침 뒤 로그인이 필요할 수 있으며, 다시 로그인하면 시트에 저장된 값이 표시됩니다.

## 실제 연결 순서

1. 재필님 Drive에 비공개 **AON 오늘의 센터 데이터** 시트 하나를 만들고, [연결·검증 안내](docs/setup.md)의 탭과 머리글을 만듭니다.
2. Google Cloud에서 웹 OAuth 클라이언트를 만들고 승인된 JavaScript 원본에 `https://kjp9204-oss.github.io`를 넣습니다. 경로는 입력하지 않습니다.
3. 시트에서 **확장 프로그램 → Apps Script**를 열어 `apps-script/`의 코드와 매니페스트를 복사합니다. 스크립트 속성에 시트 ID와 OAuth 클라이언트 ID를 넣고 재필님이 웹앱 실행 권한을 검토합니다.
4. 승인 후 Google이 발급한 웹앱 `/exec` URL과 공개 OAuth 클라이언트 ID, 확인한 문진표 주소를 `board-config.js`에 넣습니다. 클라이언트 시크릿·허용 계정 목록·시트 ID는 공개 파일에 넣지 않습니다.
5. 미리보기 검토 → 재필님 승인 → 새 저장소의 Pages 게시 후 허용·비허용 계정, 저장·갱신, 동시 수정, 모바일 및 첫 등록 5건을 확인합니다.

Claude와 Codex 정기 확인, 공지 저장, AI 작업 로그 공유 및 토스 POS Computer Use는 [업무 인계 기준](docs/workflow.md)에 분리해 기록했습니다.
